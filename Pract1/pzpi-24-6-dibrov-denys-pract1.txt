2 ЗАВДАННЯ
Метою практичного завдання є дослідження основних рекомендацій щодо написання чистого, ефективного та підтримуваного коду для мови програмування C#, а також практична демонстрація рефакторингу коду.
Основні завдання:
1. Обрати мову програмування (C#) та ознайомитися з її стандартами кодування (Microsoft .NET Coding Conventions);
2. Підготувати презентацію на 12 слайдів українською мовою;
3. Зробити відеозапис доповіді тривалістю 7–9 хвилин та завантажити його на YouTube;
4. Оформити звіт, включивши опис виконаної роботи, висновки, список джерел та додатки А (відео), Б (слайди), В (програмний код).






























3 ОПИС ВИКОНАНОЇ РОБОТИ
3.1 Дослідження стандартів та конвенцій кодування для мови C#
Під час виконання роботи досліджено екосистему платформи .NET, а також офіційні настанови компанії від Microsoft щодо написання підтримуваного коду. Однією з головних вимог якісної розробки є забезпечення високого рівня читабельності та зменшення когнітивного навантаження на команду розробників. 
Досліджено такі основні аспекти:
* організація просторів імен (Namespaces) та їх відповідність фізичній структурі каталогів проєкту;
* використання загальноприйнятих конвенцій іменування: PascalCase для публічних членів класів і методів, camelCase для локальних змінних та параметрів, а також префікса «I» для інтерфейсів;
* дотримання єдиного форматування коду, яке включає використання 4 пробілів замість табуляції, обмеження довжини рядків та уніфіковане розташування фігурних дужок за стилем Allman;
* впровадження автоматизованих інструментів перевірки стилю за допомогою файлів конфігурації .editorconfig та утиліти dotnet format.


3.2 Аналіз архітектурних патернів та безпеки коду
Окрему увагу було приділено запобіганню типовим архітектурним помилкам: 
* розроблено рекомендації щодо обробок винятків, в тому числі уникнення перехоплення загального класу Exception, заборони «мовчазного» ковтання помилок у порожніх блоках catch та обов'язкового використання конструкцій using для керування ресурсами.
* досліджено патерн «Async all the way», підкреслено важливість використання суфікса Async для асинхронних методів та критичну важливість уникнення блокування потоків через виклики .Result чи .Wait().
* проаналізовано переваги використання синтаксису методів розширення LINQ, що враховують принципи відкладеного виконання (Deferred Execution) та знижують зайві виділення пам'яті.


3.3 Практична реалізація та рефакторинг програмного коду
Для демонстрації теоретичних положень було розроблено два варіанти програмного модуля обробки даних у сервісі користувачів (UserService). 
До рефакторингу коду було виявлено кілька критичних недоліків, а саме: глибока вкладеність умовних операторів (Arrow Anti-pattern), використання жорстко зафіксованих «магічних» чисел, використання неавтентичних абревіатур у назвах параметрів (наприклад, amt) та порушення принципу єдиної відповідальності (SRP).
Після рефакторингу відбулися такі перетворення:
* на початку методу були застосовані захисні умови для швидкого відсіювання невалідних ідентифікаторів та значень, завдяки чому вдалося зменшити рівні вкладеності.
* «Магічні» числа винесено у приватні константи класу з описовими назвами (AdminDiscountRate, RegularDiscountRate).
* довгі умовні розгалуження замінено на сучасний вираз switch, що робить код більш компактним і безпечним.
* математична логіка розрахунку знижки винесена у приватний допоміжний метод ApplyDiscount для дотримання фундаментального принципу DRY (Don't Repeat Yourself).
* коректність поведінки коду до і після рефакторингу перевірено за допомогою спеціально створеного набору тестових сценаріїв, що підтверджує повну відповідність результатів бізнес-логіки.










































4 ВИСНОВКИ
У процесі виконання практичного завдання було проведено глибоке дослідження ключових принципів, рекомендацій і стандартів створення програмного забезпечення високої якості мовою C#. Було систематизовано теоретичні знання щодо стандартів оформлення коду, архітектурних конвенцій і принципів "чистого коду" (Clean Code) в середовищі .NET. Набуті практичні навички та освоєно стратегії усунення дублювання логіки, вкладених умов. Закріплено навички застосування сучасних синтаксичних конструкцій C# (вирази switch, захисні умови Guard Clauses, константи та методи розширення), які значно поліпшують читабельність та підтримуваність коду. 
Ця робота підтвердила, що дотримання стандартів написання коду та планомірне проведення рефакторингу є необхідними складовими створення надійного, масштабованого і комерційно успішного програмного забезпечення.

public class UserService
{
    public decimal ProcessUser(int id, string type, decimal amt)
    {
        if (id > 0)
        {
            if (type == "Admin")
            {
                if (amt > 0)
                {
                    return amt - (amt * 0.2m); 
                }
                else
                {
                    return 0;
                }
            }
            else if (type == "Regular")
            {
                if (amt > 0)
                {
                    return amt - (amt * 0.05m); 
                }
                else
                {
                    return 0;
                }
            }
            else
            {
                return amt;
            }
        }
        return -1;
    }
}

	//після рефакторингу


public class UserServiceRefactored
{
    private const decimal AdminDiscountRate = 0.20m;
    private const decimal RegularDiscountRate = 0.05m;


    public decimal CalculateDiscountedAmount(int userId, string userType, decimal amount)
    {
        if (userId <= 0)
            throw new ArgumentException("Invalid user ID.", nameof(userId));


        if (amount <= 0)
            return 0m;


        return userType switch
        {
            "Admin" => ApplyDiscount(amount, AdminDiscountRate),
            "Regular" => ApplyDiscount(amount, RegularDiscountRate),
            _ => amount
        };
    }
    private static decimal ApplyDiscount(decimal amount, decimal discountRate)
    {
        return amount - (amount * discountRate);
    }
}
